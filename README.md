Generate Random Passwords, learning how to use HTML, CSS, and JavaScript, instantly copy secure passwords.

How to use: 
-Open the live demo link in any browser.
-Use the checkboxes to choose what you want to include (uppercase,lowercase etc,)
-Click generate password then watch the magic happen!
-Click the copy button to save it to your clipboard

Features: 
-Customizable character sets, you can toggle uppercase letters, lowercase letters, etc.
-Adjustable length slider, you can generate passwords from 1 to 30 characters long.
-Copy your generated password with one click
-You get immediate feedback based on how secure your generated password is

How to run it locally:
-Clone or download this repo
-Open the project folder
-Double click index.html to open it directly on your web browser
